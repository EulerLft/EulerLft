## 🔭 Featured Projects
### 🚀 [Mars 2020 Mineral Classifier](https://github.com/EulerLft/Mars2020-Mineral-Classifier)
Architected automated ETL pipeline and developed the "MIP_SF" algorithm to automate stoichiometric classification of 36,000+ high-dimensional scans from the Perseverance rover. Engineered a cloud-integrated Streamlit dashboard for real-time telemetry visualizations.
- <b>The Challenge</b>: Transitioning planetary science data from static local files to a dynamic, interactive research environment.
- <b>The Solution</b>: Engineered a cloud-integrated Streamlit platform that communicates with remote GitHub repositories to process JSON/CSV datasets and render interactive visualizations in real-time.
- <b>Technical Highlight</b>: Achieved 1:1 correlation with NASA's MIST algorithm for primary igneous mineral detection.

### 📊 [Census Income Classification](https://github.com/EulerLft/Census-Income-Classification-Logistic-Regression-with-L1-Regularization)
Applied Logistic Regression with L1 Regularization to achieve 83% accuracy in predicting income levels from 1994 census data. Implemented sparsity-inducing penalties and utilized Youden's J-Statistic to optimize classification thresholds.
- <b>The Challenge</b>: Identifying primary income predictors within high-dimensional demographic data.
- <b>The Solution</b>: Implemented sparsity-inducing machine learning penalties and performed automated feature selection/dummy-encoding.
- <b>Technical Highlight</b>: Utilized Youden's J-Statistic to determine optimal classification thresholds and generated Seaborn visualizations for model interpretation.

### 🎮 [Global Twitch Viewership & Engagement](https://github.com/EulerLft/Twitch-Engagement-Data-Analysis)
Analyzed 300,000+ records using SQL and Python to uncover geographic time zone overlaps in platform traffic. Developed "Social Engagement" metrics to translate temporal data into actionable content scheduling insights.
- <b>The Challenge</b>: Identifying geographic "prime time" surges across international viewing windows.
- <b>The Solution</b>: Validated UTC timestamps and developed "Social Engagement" metrics using SQL joins and Seaborn.
- <b>Technical Highlight</b>: Translated temporal data into actionable insights for content scheduling and community management.

### 🎾 [ProTennis Predictive Modeling](https://github.com/EulerLft/ProTennis-Predictive-Modeling)
Developed a Multiple Linear Regression system to analyze ATP player statistics, achieving an $R^2$ of 0.83 in predicting player winnings. This project features a modular Python engine with Automated Experiment Tracking to log $R^2$ performance across various feature sets.
- <b>The Challenge</b>: Predict ATP player earnings using on-court performance metrics.
- <b>The Solution</b>: Developed a Multiple Linear Regression model with a modular Python engine.
- <b>Technical Highlight</b>: Built a persistent .txt logging system for automated experiment tracking and $R^2$ optimization.
